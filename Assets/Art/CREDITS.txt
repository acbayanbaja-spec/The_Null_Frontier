NULL FRONTIER - third-party art provenance
===========================================

Every 3D model and animation under this folder is external, licensed content.
None of it was drawn or modelled for this project. Keep this file with the build.

Recorded below are the exact archive URLs the files were pulled from, so the
provenance can be re-checked by a third party.

Quaternius - Ultimate Animated Character Pack (Nov 2019)
  Download https://opengameart.org/sites/default/files/ultimate_animated_character_pack_by_quaternius.zip
  Author   Quaternius (creatorquaternius@gmail.com)
  License  CC0 1.0 Universal (see note below)

  Files    Quaternius/Characters/  (FBX format only, 9 of 52 models)

Solar System Scope - Earth texture maps
  Download https://www.solarsystemscope.com/textures/download/2k_earth_daymap.jpg
           https://www.solarsystemscope.com/textures/download/2k_earth_clouds.jpg
  Author   Solar System Scope (https://www.solarsystemscope.com/)
  License  CC BY 4.0 - https://creativecommons.org/licenses/by/4.0/
  Used for the planet seen through the menu gate: the day albedo and the cloud
  shell. Both are 2:1 equirectangular maps built from NASA Visible Earth /
  Blue Marble imagery and re-published by Solar System Scope.
  Files    Space/Earth_Day.jpg (2048x1024), Space/Earth_Clouds.jpg (2048x1024)
  Attribution: "Earth texture by Solar System Scope, CC BY 4.0". Required by
  the licence if the planet image is shown publicly; it lives in the credits
  screen and in this file.
  Note: NASA's own Blue Marble host (eoimages.gsfc.nasa.gov) is unreachable
  from the build machine, so the Solar System Scope re-publication was used
  instead of the original. Both trace back to the same NASA source imagery.

Not imported on purpose
-----------------------
The packs also ship .blend, .obj, .dae and .glb copies plus preview renders.
Only the FBX copies and their single shared texture atlas were imported, so the
build does not carry duplicate formats or thumbnails.

Derived assets
--------------
Assets/Art/Materials/ and Assets/Art/Rigs/ are generated by
Null Frontier > Rebuild Generated Assets. They are derived from the models above
(URP materials and per-character Animator Controllers) and inherit their licence.
